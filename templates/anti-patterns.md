# 反模式清单（Anti-Patterns）

> **维护者**：项目团队 | **审计者**：Tester（审查时强制匹配）

本项目记录的已知破坏性场景。Tester 在执行对抗式审查时必须逐一验证，覆盖率 100%。

## 格式

    ### AP-<CATEGORY>-<NNN>: <标题>
    
    - **描述**: 发生了什么、为什么坏
    - **重现条件**: 触发此反模式的上下文
    - **修复方式**: 当时采用的修复方案
    - **验证方式**: 如何确保不再复发
    - **@ptg**: true/false — 标记是否在 PTG 中自动化验证（推荐全部为 true）

## 分类代码

| 前缀 | 类别 |
|------|------|
| SCHEMA | 数据库/Schema 偏离 |
| ENV | 环境不一致 |
| MIGRATE | 迁移缺失/错误 |
| CONCURRENT | 时序/并发问题 |
| RESOURCE | 资源边界/性能 |
| CONTRACT | 契约断裂 |
